# Известные ограничения Alpha 43

Alpha 43 проверена статически: валидатор (0 ошибок), юнит-тесты, тесты скриптов KubeJS на моделях API,
сверка ID и поведения с JAR модов. **Minecraft не запускался** — ни клиент, ни сервер. Всё ниже —
то, что может проявиться только в игре.

## Нужно подтвердить в первом игровом тесте

- **Команда и награды.** Ожидается: Максим и Юра в одной команде FTB Teams, прогресс задач общий,
  каждый получает свою копию предметной награды. Не проверено.
- **Достижения — личные.** Задача-достижение засчитывается команде, когда его получил любой игрок.
  Для одиночных условий это удобно; составных достижений «всё одному игроку» в книге нет.
- **Задачи `kill`** считают только убийства, где добивал игрок (не артиллерия, не питомец) и только после
  установки Alpha 43. Касается «Восьми побед Катаклизма» и пяти задач на мобов.
- **Победы артиллерией** Create Big Cannons засчитываются игрокам в радиусе 128 блоков от жертвы
  (у снаряда нет владельца). Игрок, стоящий дальше, не получит засчёт.
- **Сокровищницы и записки в сундуках.** Задачи «открыть сундук» срабатывают при первом формировании
  добычи для игрока (Lootr — отдельно на каждого). Сундук, уже открытый этим игроком, повторно не засчитается
  и новой записки не даст.
- **Имена боссов** меняются только при русском языке игры; подсказки и записки — на русском при любом языке.
  Подсказки — клиентский скрипт, записки — серверный; после обновления `kubejs` нужен полный перезапуск игры.
- **Чужие деревни.** Торговля и сон засчитываются, только если игрок стоит внутри части постройки (дом, улица),
  а не просто рядом. Эксклюзивные деревни Towns and Towers появляются лишь в отдельных биомах Terralith,
  поэтому многие из них редки; в книгу взяты только те, что могут появиться в этой сборке.
- **Производственные испытания** (`docs/FACTORY_TRIALS.md`): скрипт проверен на моделях, его тики,
  мост к Java и зачёт FTB в игре не испытаны.
- **Графы глав.** Схемы `tools/preview.py` повторяют координаты, формы и линии, но не шрифты и рамки FTB.
  Пять длинных линий (Катаклизм, Летопись, «Звери и стражи») просмотрены и оставлены намеренно.
- **Фоны глав.** Подключение по главе проверено по байткоду FTB Quests, вид — только на превью
  `tools/preview.py --screen` (значки 3D-предметов там плоские, кнопки интерфейса не нарисованы).
  Картинка растягивается на всё окно: на экране не 16:9 она слегка сплющится или вытянется.

## Чего книга не делает

- Не отслеживает уровень реликвий Relics и устройство механизмов, у которых нет достижения или
  предмета-результата: такие цели заменены проверяемыми (коллекции, достижения, контрольные выпуски).
- Не переносит прогресс квестов Alpha 42 с удалёнными ID (см. `docs/ALPHA43_CHANGELOG.md`).
- Не меняет модели, постройки и поведение мобов: адаптация модов — только имена, подсказки и добыча.
