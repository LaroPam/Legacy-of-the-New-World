# Политика наград

Действует с Alpha 43. Основа — разбор `docs/REWARD_REVIEW.md` (Alpha 42) и пожелание автора:
«щедро, тематично, чуть больше модовых вещей».

## Принципы

1. **Награда соответствует этапу, а не только усилию.** Приз полезен сейчас и не перепрыгивает
   ступень прогрессии: за первый ветряк — не регулятор скорости, за посещение — не добыча босса.
2. **Тематично.** Награда продолжает действие квеста: за кожаный пояс реликвий — пузырёк опыта
   реликвии, за лошадиную флейту — конская броня, за эндер-грипп — хорус и молоко.
3. **Боссы — памятные вещи.** Редкий тематический предмет, пластинка босса и/или запись дневника
   вместо горы обычных ресурсов.
4. **Модовые вещи предпочтительнее ванильных** при равной пользе: улучшения рюкзаков и хранилищ,
   детали Create, артефакты, предметы Alex's Mobs/Caves, Farmer's Delight.
5. **Награды есть у каждого содержательного квеста.** Опыт — всегда; пустые формальные призы
   (три латунные решётки за редкую реликвию) не допускаются.
6. **Подарок не выполняет чужое задание.** Предмет-награда не может быть целью другого квеста
   (Item Task или `inventory_changed` в достижении). Валидатор проверяет это автоматически
   (`reward_completes_task`); исключения не делаются — меняется награда.
7. **Без дублей внутри квеста** и без тройного одинакового оружия: награды в FTB Quests
   2001.4.22 по умолчанию персональные, каждый из двух игроков получает свою копию.
8. **Книги-записи** (`minecraft:written_book`) — только награды сюжетных квестов, никогда не условия.
   Название — не длиннее 32 символов, иначе клиент не откроет книгу.

## Ориентиры по опыту

Медианы Alpha 43 по формам квестов (форма отражает значимость):

| Форма | Смысл | Медиана XP | Максимум |
|---|---|---|---|
| `gear`, `coin`, `square` | технический или торговый шаг | ~150 | 250 |
| `circle` | обычный шаг | ~190 | 700 |
| `scroll` | экспедиция | ~240 | 1200 |
| `shield` | опасное испытание | ~300 | 600 |
| `star` | особое достижение | ~400 | 5000 (финал) |
| `crown` | босс | ~1400 | 3000 |

Опыт нужен не только для чар: реликвии Relics тратят ванильный опыт на улучшение способностей.

## Кто получает награду

Игроки — одна команда FTB Teams. Прогресс задач общий; предметные награды персональные —
каждый забирает свою копию. Это ожидание по умолчанию FTB Quests 2001.4.22; фактическую
выдачу обоим игрокам нужно подтвердить в первом игровом тесте.

## Проверка нового ID награды

Каждый новый предмет сверяется с `references/registry.json` (собран из JAR сборки) — валидатор
отвергает несуществующие ID. Связь с прогрессией (рецепт, добыча, этап) сверяется вручную по JAR.
