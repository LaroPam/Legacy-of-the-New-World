# Текущее состояние и дорожная карта

## Состояние (Alpha 43, 2026-10-23)

- **Книга переписана целиком** как одна история «Наследие нового мира»: «Летопись» сверху,
  четыре акта, финал в Краю и две свободные главы. 19 глав, 498 квестов, 26 книг-записей.
  Состав глав и все изменения ID — `docs/ALPHA43_CHANGELOG.md`; сюжет — `docs/STORY.md`.
- **История в модах**: сюжетные имена боссов, подсказки к предметам, страницы экспедиции в сундуках.
- **Проверки**: валидатор (0 ошибок, 5 просмотренных длинных линий), юнит-тесты, тесты скриптов KubeJS,
  сверка ID с JAR сборки. Найденные статикой игровые ошибки исправлены (см. журнал изменений).
- **Игровой тест не проводился.** Это главный открытый вопрос: `docs/ALPHA43_TEST_CHECKLIST.md`.
- Архив для установки — `reports/alpha43/` (`python tools/package_release.py`).

## Как устроена работа

Источник — `src/chapters/*.yaml`; SNBT и достижения KubeJS генерируются (`tools/questbook.py`).
Правила проверок и выпуска — `docs/VALIDATION_AND_RELEASE.md`, награды — `docs/REWARD_POLICY.md`,
решения автора — `docs/ALPHA43_PLAN.md`. Прогресс старого мира для Alpha 43 беречь не нужно,
но старый ID никогда не получает новый смысл.

## Дорожная карта

1. **Игровой тест Alpha 43** вдвоём: быстрая проверка в тестовом мире, затем обычная игра.
2. **Alpha 44 — исправления по тесту**: условия, которые засчитываются не так, баланс наград,
   читаемость графов в настоящем интерфейсе FTB.
3. **Больше истории в модах** (по желанию автора): новые страницы экспедиции, подсказки, возможно —
   сюжетные рецепты. Только через `kubejs/`, без правки JAR и без поломки прогрессии модов.
4. **Что почти не задействовано** и может стать побочными ветками: Bountiful (доска заказов),
   Tombstone, Interiors и Copycats (обустройство), деревни CTOV и Towns and Towers. Epic Fight —
   боевая механика без квестов; Twilight Forest не добавляется.
